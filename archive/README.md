# 历史归档（不部署）

`hugo/` 原样保存迁移前的文章、About 页面、图片、配置和完整 HTML 产物。
4 篇 Markdown 博文以及仅存在于旧 HTML 中的页面都保留，不参与 Astro 内容集合。

此目录不在 `public/` 中，Actions 仅上传 `dist/`。旧正文不会进入新网站的页面、RSS 或 sitemap。
目录名和构建排除不是访问控制：仓库公开时，归档和 Git 历史仍可通过 GitHub 读取。

如需重新发布，手动复制所需文章到 `content/posts/`，按根目录 README 更新元数据并审阅内容。
构建检查会阻止旧标题和旧路径重新上线；确认要重新公开后，应同步调整该检查中的历史排除规则。
